# Checklist riêng từng dự án

Bỏ file checklist của dự án vào đây (định dạng .md hoặc .txt), đặt tên theo hệ thống:

- vnedu.md
- hss.md
- ioc.md
- tsdc.md

Khi chạy `/test-task`, AI tự đọc file trùng tên hệ thống và đối chiếu mô tả Jira với các quy tắc trong đó.
Chưa có file thì AI chỉ dùng 3 checklist chung ở thư mục `checklists/`.
